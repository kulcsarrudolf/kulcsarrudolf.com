# TeX Gyre Termes

Version 2.609 from the GUST e-foundry,
<https://www.gust.org.pl/projects/e-foundry/tex-gyre/termes>, distributed under the
GUST Font License in `GUST-FONT-LICENSE.txt` beside this file.

These are not the original files: each OTF was subset to Latin and Latin Extended
(`U+0000-024F`, general punctuation, the euro and trade mark signs) and converted to
WOFF2 with fontTools `pyftsubset`, for the wedding page at `/nr`.
